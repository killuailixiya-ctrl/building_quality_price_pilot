# 论文变量口径对照

论文将房价影响因素分为 8 个维度。每个变量只采用一种合理测度，不是同时使用数量和距离。

## 8 个维度

| 维度 | 论文变量 | 测度方式 |
|---|---|---|
| 主观感知 | 街景感知、建筑感知 | 图像成对比较 + TrueSkill + 深度学习预测 |
| 教育设施 | 幼儿园 | 核密度 KDE |
| 教育设施 | 小学、初中、大学 | 到最近设施距离 |
| 医疗设施 | 医疗保健（诊所/药店等） | 核密度 KDE |
| 医疗设施 | 三甲医院 | 到最近三甲医院距离 |
| 商业服务 | 餐饮、购物、休闲娱乐、公司企业 | 核密度 KDE |
| 交通条件 | 地铁站 | 到最近地铁站距离 |
| 交通条件 | 公交站 | 核密度 KDE |
| 结构属性 | 容积率、房龄、物业评分 | IDW 插值到街区 |
| 区位属性 | 三环线距离 | 到三环线距离，内正外负 |
| 景观环境 | 风景名胜/公园 | 到最近景点距离 |
| 景观环境 | 绿地影响 | 1km 缓冲区绿地占比 |
| 景观环境 | 水域影响 | 50m 网格点核密度 |

## 论文处理顺序

1. 房价：小区点数据先 IDW 插值，再分区统计到街区。
2. 结构属性：IDW 插值，再分区统计到街区。
3. 供给强度变量：KDE 后分区统计均值。
4. 可达性变量：计算街区到最近设施距离。
5. 景观绿地：1km 缓冲区绿地占比。
6. 景观水域：在水体面内生成 50m 规则网格点，再做核密度。
7. VIF 剔除共线性变量，论文最终剔除了餐饮服务。

## 我们当前代码与论文的差异

1. 当前多数 POI 变量用了“数量”而不是论文要求的 KDE。
2. 当前水域影响只用 landcover 的 water_ratio，而不是论文的 50m 网格点核密度。
3. 当前绿地影响用了 landcover 的 green_ratio，基本接近论文的缓冲区绿地占比。
4. 当前三环线距离已加入。
5. 当前房价已使用 IDW。
6. 当前建筑品质分是迁移代理分，不是建筑图人工评分。
