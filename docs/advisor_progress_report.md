# 研究阶段汇报：住区建筑品质对房价影响的多城市扩展预实验

## 1. 研究目标

参考武汉大学硕士论文的研究思路，探索：

> 住区建筑图像所反映的建筑品质，如何影响居民居住意愿，并最终体现在房价/租金的空间差异上。

本次预实验先以武汉为样本，验证“建筑图像 → 建筑品质分 → 道路街区聚合 → 房价模型”的完整技术路线，为后续扩展到北京、上海、广州、武汉多城市比较做准备。

## 2. 当前研究范围

- 研究区：武汉全市域，并进一步限定三环线内主城区。
- 时间：2017–2022 年多年份数据。
- 空间单元：OSM 道路网围合街区。
- 因变量：街区房价。
- 核心变量：建筑品质分、POI 密度、设施距离、地铁距离、绿地、水域、三环线距离、三镇区域。

## 3. 数据来源

主要来自 G 盘：

- 安居客 2022 小区房价与建筑照片
- 安居客历史房价 2017–2022
- 高德 POI
- OSM 路网
- 武汉地铁
- NDVI 与土地覆盖
- 武汉市行政区划与环线

## 4. 已经完成的工作

1. 完成安居客房价清洗、建筑照片匹配、小区坐标地理编码。
2. 用 OSM 路网生成道路街区。
3. 用本地 EfficientNet 模型生成建筑图像品质代理分。
4. 用 ADE20K 语义分割过滤非建筑图像。
5. 构建论文口径变量：
   - KDE：幼儿园、基础医疗、餐饮、购物、休闲娱乐、公司企业、公交
   - 最近距离：小学、初中、大学、三甲医院、公园、地铁
   - IDW：房价、房龄、容积率
   - 景观：NDVI、绿地、水域
   - 区位：三环线距离
6. 完成 VIF 筛选。
7. 运行 OLS、RF、GWR、GWRF。
8. 输出 SHAP、PDP 和 Grad-CAM 示例。

## 5. 当前模型结果

### 论文口径多年份 + 三镇区域

| 模型 | R² | RMSE | MAE |
|---|---|---|---|
| RF | 0.746 | 0.145 | 0.095 |
| GWRF | 0.783 | 0.134 | 0.091 |

### 单年份论文口径

| 模型 | R² |
|---|---|
| RF | 0.293 |
| GWRF | 0.495 |

## 6. SHAP 主要结论

当前重要性前几位：

1. 到市中心距离
2. 汉口
3. 武昌
4. 初中距离
5. 建筑品质分
6. 幼儿园距离
7. 地铁距离

说明：

- 区位和区域仍是房价最强的解释因素。
- 教育、地铁、公园、基础医疗等建成环境变量具有稳定影响。
- 建筑品质分已进入重要变量，但目前仍是迁移代理分，尚未达到论文中人工建筑评分的解释力。

## 7. 当前主要问题

1. **建筑品质分不是真正的建筑人工评分。**
   当前使用的是街景质量模型迁移到建筑图像上的代理分。

2. **地铁变量还不是逐年动态。**
   现有数据没有线路/站点开通年份，暂时使用当前运行线路近似。

3. **缺少部分精细小区属性。**
   如学区质量、楼层、户型、朝向、江景/湖景等。

4. **论文中的部分年份缺失。**
   目前有 2017–2022，但论文为 2016、2018、2020、2022、2024。

5. **住宅租金尚未纳入。**
   未来多城市扩展需要同时考虑房价和租金。

## 8. 下一步计划

1. 补建筑图像人工成对比较标签，训练真正的建筑质量模型。
2. 补地铁线路/站点开通年份，实现逐年地铁距离。
3. 补 2016、2020、2024 年房价。
4. 补住宅租金数据。
5. 把武汉流程复制到北京、上海、广州，形成四城比较。
6. 对四城分别运行 OLS/GWR/RF/GWRF，输出 SHAP/PDP/Grad-CAM。
7. 撰写预实验技术报告。
