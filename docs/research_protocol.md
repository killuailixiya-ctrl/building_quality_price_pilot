# 研究协议

## 目标

验证从建筑图像提取建筑品质、并将其映射到道路街区后解释武汉房价差异的技术可行性。

## 数据与口径

- 研究区：武汉全市域。
- 时间：2022 年。
- 空间单元：2022 OSM 道路网围合街区。
- 因变量：小区挂牌均价，元/㎡。
- 主观感知：仅建筑感知。
- 客观变量：教育、医疗、商业、交通、结构、区位、景观七类。

## 分析步骤

1. 清洗安居客小区表，匹配建筑照片。
2. 地理编码小区，生成道路街区并空间连接。
3. 建筑/非建筑分类，计算建筑品质代理分，聚合到街区。
4. 构建客观变量，形成特征矩阵。
5. OLS/GWR/RF/GWRF 建模，SHAP/PDP 解释。
