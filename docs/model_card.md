# 模型卡

## 建筑/非建筑图像分类

- 目标：识别小区照片中是否为建筑外观/立面图。
- 模型：EfficientNet-B0 迁移学习；若无 GPU，可用 CLIP 零样本或轻量 ResNet。
- 训练/验证：人工标注约 600-800 张，7:3 划分。
- 指标：F1 ≥ 0.90。

## 建筑品质代理评分

- 目标：为建筑图生成连续品质分。
- 预实验：预训练视觉模型嵌入 + 文本提示相似度，或小样本岭回归校准。
- 校准：约 100 张人工排序，Spearman ≥ 0.65。
- 正式研究：成对比较 + TrueSkill + EfficientNet 回归。

## 房价模型

- 模型：OLS、GWR、RF、GWRF。
- 因变量：`log(block_price)` 或标准化房价。
- 评估：R²、MAE、RMSE；SHAP 和 PDP 做解释。
